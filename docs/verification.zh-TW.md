## 發行包檢查方式

`scripts/release.sh v1.0.2` 以 `CGO_ENABLED=0` 產生 Linux amd64、arm64 執行包與原始碼包，再建立 `SHA256SUMS`。每個執行包僅需執行其中的 `healthbank`，前端已內嵌。正式封裝前重新建置前端，以清除僅供本機尺寸檢查的暫存頁面。用以下方式核對收到的發行檔案：

```bash
sha256sum -c SHA256SUMS
```

校驗清單驗證檔案是否與本次封裝一致，不是第三方簽署或認證。原始碼包需依 README 重建，不含編譯快取或已編譯的前端目錄；已釘選的前端 vendor 輸入則會保留。

## 驗收時應保留的判讀界限

五級顏色是應用程式顯示規則；一般參考區間不會自動生成五個醫學危險門檻。完整項目、已啟用規則、只供參考而尚未啟用的規則及來源版本，見 `docs/clinical-reference.zh-TW.md`。

另存網頁只能證明實際包含的明細，不能證明整份歷史都已下載。匯入及合成示範不會連到已驗證身分的永久設定。跨裝置永久設定依賴真實官方登入成功；這個驗證文件不會把本地合成協定測試等同於官方實際登入驗收。
