## 一、使用者角度

### 看得清楚，操作不被版面擋住

比較表維持「日期為列、檢驗項目為欄」。手機直向與短橫向不固定日期欄及年度標題；桌面繼續固定日期，方便跨欄比較。頂部提供可見的左右按鈕及滑桿，避免只依賴作業系統可能隱藏的原生捲軸。

本輪實際發現：給螢幕閱讀器新增的隱藏說明採絕對定位，但表格捲動容器沒有自己的定位區域，因而撐大整頁。修正讓文字由當地捲動容器定位，沒有把整頁溢出隱藏來掩蓋問題。修正後在 200% 應用字級下，量測如下：

| 桌面 Chromium 的尺寸容器 | 頁面可視寬／內容寬 | 日期欄 | 合成結果 |
| --- | --- | --- | --- |
| 320×568 | 305／305 px | 84 px，不固定 | 82 筆 |
| 390×844 | 375／375 px | 96 px，不固定 | 82 筆 |
| 844×390 | 829／829 px | 96 px，不固定 | 82 筆 |
| 1280×800，100% 字級 | 1265／1265 px | 189 px，固定 | 82 筆 |

頁面寬度與容器寬度差異包含瀏覽器捲軸。390 px 視窗的右箭頭實際前進 293 px，滑桿 End 到達最後一欄；在橫向視窗從末端使用 Tab，第一個項目按鈕會完整進入可視區。資料欄仍可獨立橫向捲動。

趨勢圖按實際日期呈現完整所選期間，不把不等式、區間或缺值補成精確資料點。390 px 及 320 px、200% 字級下，圖表分別為 345 px 與 275 px 寬，8 個合成精確觀測點均保留，日期及版權文字沒有超出 SVG 邊界。文字放大仍會增加垂直閱讀長度；這不是保證整個頁面無須垂直捲動。

### 設定能理解，也能還原

尚未登入、尚未匯入資料，即可看到 76 組內建設定。參考範本、來源分類、獨立警示及個人覆寫分開標示；沒有為了湊滿五種顏色而捏造所有檢驗的通用危險分期。個人綠色區間不能降低仍適用的獨立警示，原院參考值與原始異常標記也會保留。

已實際編輯及單獨還原三酸甘油脂基準，並修改兩項後使用確認視窗「還原全部基準」。完成後覆寫為零、還原按鈕停用，深色外觀與 200% 閱讀字級保留。匿名操作只屬於目前使用階段；跨裝置個人設定仍須經官網身分驗證成功後才能連結。

### 輔助閱讀與內容可信度

修正設定及比較表按鈕的可見文字與無障礙名稱不一致、無效 ARIA 屬性，以及 SVG 互動點被包在圖片語意下的問題。保留真實文字描述與鍵盤操作，而非移除可及性檢查。

axe-core 4.14.0 在本輪所檢查的設定、總覽、編輯、比較表、趨勢及明細狀態均回報零違規，但仍有工具無法判定的對比項目。22 個比較表箭頭以實際實色背景另行計算，淺色 5.73:1、深色 8.38:1；SVG 背景、參考區間及部分重疊文字仍需人工判讀。這不是完整 WCAG 認證、VoiceOver 驗收或所有操作狀態的保證。

### 零警告來自修正問題

ESLint 使用 strictTypeChecked、目前 React Hooks recommended-latest、完整 switch 檢查、型別匯入檢查及 `--max-warnings 0`。14 個自有前端、腳本、設定與測試檔為 0 errors、0 warnings、0 suppressed messages。兩個有文件的規則選項允許數字插入畫面文字／SVG 座標，以及 React void callback 的簡潔箭頭寫法；沒有改成停用規則或忽略整個檔案。未使用的 disable 指令會成為錯誤。

實質修正包括：

- 瀏覽器儲存的 JSON 從 unknown 驗證形狀與值後才採用，避免直接斷言可信型別。
- 對空紀錄、相鄰點、可選欄位與非同步 Promise 做明確處理；嚴格檢查新增索引可能不存在及 exact optional semantics。
- 使用階段切換後，較早的設定、報告、目錄或 CSRF 回應不再覆寫新的狀態；關閉或更換驗證碼會取消前一請求。
- CSV 對負號開頭的公式運算式進行防護，同時保留完整負數及科學記號。
- 將大量資料的 `Math.min(...values)`／`Math.max(...values)` 改成迭代計算，修正 150,000 個圖軸值造成呼叫堆疊溢出的情況。
- 正式驗證碼讀取與診斷工具共用完整 PNG／JPEG／GIF 解碼、512 KiB 上限及 2048×2048 尺寸限制；不再只憑圖片檔頭宣稱成功。
