文件版本：v1。來源查核日期：2026-10-27（臺灣時間）。

本文件說明目前程式實際採用的辨識、參考區間與提醒規則，供閱讀報表的使用者及維護者共同查核。內建目錄包含 **72 個項目定義：70 個檢驗／觀察項目，以及 2 個檢驗流程附註**。數值、定性文字、半定量結果都可能是觀察項目；「70 個」不表示每項都有五段數字門檻。

**L1–L5 是本應用的顯示級別，不是一套適用全部臺灣人或亞洲人的「2026 年通用危險分級」。** 不同項目的顏色可能表示原院參考區間、來源指引的分類，或使用者自己的目標。請一起閱讀原始結果、單位、原院參考值、來源旗標與規則說明；不同項目的同一顏色不能直接比較疾病嚴重程度。

## 一、先看這四層資訊

| 資訊 | v1 的含義 |
| --- | --- |
| 原始結果 | 保留原文字，包括小數、不等號、區間、加號、`Negative`、`Not Found` 等；不以顏色取代結果。 |
| 本筆原院參考值 | 直接來自該筆資料，與其檢查當時的來源情境一起保存於本次工作階段。 |
| 原院旗標／參考狀態 | 官方回傳的原始旗標獨立保留；程式另外判斷結果是否完整位於可解析的原院區間。兩者不保證等同。 |
| 應用顏色與說明 | 表示目前規則或個人設定的判讀。改變個人設定不會改寫前述原始欄位。 |

基本配色如下；深色模式會調整背景與文字對比。

| 顯示 | 色系 | 正確讀法 |
| --- | --- | --- |
| L1 | 綠 | 依本項目前使用的規則位於基準內；不能推論其他項目也正常。 |
| L2 | 黃 | 某些有來源的分類使用此級；通常表示邊界或需要留意。 |
| L3 | 橙 | 常用於偏離原院參考值，或某個指引分類；不是已校準的中度疾病危險率。 |
| L4 | 紅 | 顯著異常／需要評估的應用提醒；須閱讀適用規則。 |
| L5 | 紫 | 本應用最高警示；不等同已確診急症或所有人都必須住院。 |
| 未判定 | 灰 | 缺值、附註、單位或規則不足，或結果無法唯一分類；灰色不表示安全。 |

一般「原院參考區間」規則只使用 L1、L3、未判定。ACR、UPCR 等來源也不會用滿五個級別。**未使用的級別是刻意保留，程式不會用偏離百分比補出缺少的危險門檻。**

## 二、項目辨識與原院參考值

### 名稱、醫令代碼與單位必須一起判斷

內建定義以醫令代碼、項目名稱與單位配對。項目名稱保留大小寫區別；單位僅整理常見空白、微升符號及上標表示法，不執行一般性的濃度換算。找不到已知配對時，會建立獨立的動態項目，並保留原院參考值；不因名稱看起來相似就套用另一項門檻。

例如，尿液 `PH` 與靜脈血 `pH`、尿液 `Albumin` 與血清 `Albumin`、尿液鏡檢 `R.B.C.` 與血液 `RBC` 都是不同項目。`mg/L` 的尿白蛋白濃度不等於 `mg/g` 的 ACR，`mg/dL` 的隨機尿總蛋白也不等於 UPCR。[KDIGO 的方法對照表同樣說明這些測量方式不能直接視為等值。][S2]

ACR 半定量與定量保留各自的結果紀錄，但共用一個已確認相同單位尺度的設定鍵 `urine_albumin_creatinine_ratio`，設定頁不重複建立兩套門檻。未曾出現實際結果的項目、缺值與流程附註，不會預先塞滿設定頁。

### 每一筆資料使用自己的原院參考值

v1 不會從使用者年齡、性別、居住地或檢驗數字推定適用族群，也不會在原院參考值缺失時，自動套用某院手冊、男性／女性範本或檢測方法專屬區間。

- `[下限][上限]` 以含端點的區間處理；只有一邊有有效數字時，可保留單側界限。
- 明確數字區間與 `≥`、`≤` 可解析為數值界限；嚴格的 `<`、`>` 原院參考文字目前只保留文字，不放寬成含等號的界限。
- 沒有參考值、上下限顛倒、資料無法解析時，不憑空補齊。
- 小數先按精確十進位意義比較，不會先四捨五入再決定是否超界。
- 本次檢查日期與就醫／入院日期分開保留。無法辨識檢查日期時，不會拿就醫日期代替。

內建目錄中的部分 `reference_profile` 是整理用的參考範本；**v1 引擎不把它們當作缺值時的自動替代值**。設定頁顯示的原院上下限來自目前可取得的報告資料。

## 三、目前啟用的來源分類

以下數字是規則邊界，不是任何人的檢驗結果。表內以 `x` 表示本項目的有效測量值；負濃度或其他不合理物理範圍不會被當成低風險值。

### 1. 三酸甘油脂：成人方向的 mg/dL 規則

本應用綜合 [NHLBI 的成人分類][S3] 與 [ACC 2021 共識的嚴重升高界限][S4] 建立五色顯示。

| 條件，mg/dL | v1 顯示 | 分類重點 |
| --- | --- | --- |
| `0 ≤ x < 150` | L1 | 低於此成人分類界限。 |
| `150 ≤ x < 200` | L2 | 邊界升高。 |
| `200 ≤ x < 500` | L3 | 升高。 |
| `500 ≤ x < 1000` | L4 | 顯著升高，需評估。 |
| `x ≥ 1000` | L5 | 最高提醒區間，需注意胰臟炎相關情境。 |

v1 沒有空腹狀態欄位可自動確認；尤其較低幾級的解讀，應一併確認是否空腹。顯著升高合併腹痛、嘔吐等症狀需及時醫療評估；單憑歷史數值及顏色不判定目前急症。[ACC 2026 臨床教育案例][S5]支持症狀與濃度一起評估，不是另一套「全亞洲五級標準」。

### 2. 尿白蛋白／肌酸酐比值 ACR

依 [KDIGO 2024 表 3][S1]，本規則接受 `mg/g`，以及本目錄已確認對應相同尺度的 `mg/gCr`。

| 條件 | KDIGO 類別 | v1 顯示 |
| --- | --- | --- |
| `0 ≤ x < 30` | A1 | L1 |
| `30 ≤ x ≤ 300` | A2 | L3 |
| `x > 300` | A3 | L4 |

`300` 這個精確端點屬本表採用的 A2；`≥300` 則同時包含 A2 的端點與 A3，不能直接改寫為 `300`，也不能在預設規則下指定單一 A 類別。此項不杜撰 L2、L5 的分界。

### 3. 尿總蛋白／肌酸酐比值 UPCR／PCR

採用 [KDIGO 2012 指引表 7][S2]的歷史總蛋白比值分類；該指引於 2013 年刊行，不能稱為 2026 年新制。

| 條件，mg/g | v1 的總蛋白分類 | v1 顯示 |
| --- | --- | --- |
| `0 ≤ x < 150` | 正常至輕度增加 | L1 |
| `150 ≤ x ≤ 500` | 中度增加 | L3 |
| `x > 500` | 顯著增加 | L4 |

這是總蛋白比值的顯示分類，不把它改標成尿白蛋白的 A1–A3 分期，也不根據這份近似對照表自行重算另一種檢驗。

### 4. eGFR：必須有可確認的單位

依 [KDIGO 2024 表 2][S1]，目前接受 `mL/min/1.73m2` 及等同的上標寫法。

| 條件，mL/min/1.73m² | G 類別 | v1 顯示 |
| --- | --- | --- |
| `x ≥ 90` | G1 | L1 |
| `60 ≤ x < 90` | G2 | L2 |
| `45 ≤ x < 60` | G3a | L3 |
| `30 ≤ x < 45` | G3b | L3 |
| `15 ≤ x < 30` | G4 | L4 |
| `0 ≤ x < 15` | G5 | L5 |

五種顏色容納六個 G 類別，因此 G3a、G3b 同為 L3，但文字分類仍分開。單次結果不能建立慢性病程；G1／G2 也不能單獨排除腎損傷，還須結合白蛋白尿與其他資料。[S1]

若來源單位是「無單位」，v1 **不猜成 mL/min/1.73m²，不套用 G 分類，也不允許個人 eGFR 門檻繞過這項檢查**。若原報告另外提供自己的參考區間，原院參考狀態仍會保留；那不等於完成 KDIGO 分級。v1 也不自行重算 eGFR 公式。

### 5. 獨立的低血糖提醒

目前用於已辨識的血液葡萄糖項目，且單位為 `mg/dL`；不把尿糖加號視為血糖。依 [ADA Standards of Care 2026 第 6 節][S6]：

| 條件，mg/dL | ADA 數值類別 | v1 提醒 |
| --- | --- | --- |
| `54 ≤ x < 70` | 第 1 級低血糖 | 至少 L4 |
| `0 ≤ x < 54` | 第 2 級低血糖 | 至少 L5 |

本應用 L4／L5 與 ADA 第 1／2／3 級是不同編號系統。ADA 第 3 級依需要他人協助等臨床情況界定，不能只靠檢驗數字判斷。這項數值提醒不以「已確認空腹」為前提。

## 四、不等式、範圍與「至少」的含義

精確數字才會提供趨勢圖用的單點數值；`>`、`≥`、`<`、`≤`、`大於`、`小於` 及有效數字區間都保留其原始含義。只有全部可能數值落在同一來源分類時，才指定該分類。

對三酸甘油脂顯著升高與低血糖，還有獨立的「最低可確定警示」。如果整個可能區間都達到警示，但跨越 L4、L5，仍可顯示**至少 L4**，不能因此推定某個精確結果。

下表是程式邊界示例，不是個人報告：

| 規則示例 | v1 處理 |
| --- | --- |
| TG `>500`、`500–1500` mg/dL | 跨越來源分類，但所有可能值至少達 L4；不產生趨勢單點。 |
| TG `≥1000` mg/dL | 所有可能值達 L5；仍保留不等式。 |
| 血糖 `≤60`、`≤54` mg/dL | 可能涵蓋 ADA 第 1 與第 2 級；至少 L4，不能直接稱為第 2 級。 |
| 血糖 `<54` mg/dL | 全部可能值達本應用 L5。 |
| 血糖 `≤70` mg/dL | 包含不屬於低血糖門檻的端點；不產生「必定低血糖」的獨立最低警示。 |
| ACR `≥300` mg/g | 跨 A2／A3；預設不指定單一 A 類別。 |
| 缺值 `-`、空字串 | 無結果；不等於零，也不補一個圖表點。 |

此處的「至少」來自完整區間與已核對來源區間的比較；程式不會把未涵蓋的端點或區間空隙視為已涵蓋。個人設定可以更嚴格，但不能把已確定的 TG／低血糖警示改成較低級別。

## 五、個人設定與其他重要情境

### 個人設定改變顯示，不改寫來源

可以為實際出現的項目設定個人上下限或多段級別，並明確設定各段是否包含端點。上下限不得顛倒，分段不得重疊。兩段在同一數字相接時，不能同時把該端點算入兩段。

個人設定的結果會標示來源為個人設定。原院參考上下限、原始參考文字、原院高／低參考狀態與官方旗標仍保留。套用個人規則後，獨立的 TG／低血糖最低警示仍再檢查一次。未確認單位的既有數值規則不會因個人設定而自動變成已確認。

### HbA1c、血紅素及性別／方法差異

HbA1c 預設採本筆原院參考值，不把篩檢診斷界值當成個人治療目標，也不將接受治療者重新貼上「前期」等診斷標籤。低於原院下限的 HbA1c 仍保留低值標記，不因數值低於糖尿病診斷界值就改稱安全。[CDC 篩檢說明][S7]與本產品的逐筆參考值用途須分開閱讀。

血紅素 Hb、Hct、RBC、肌酸酐、尿酸、NT-proBNP 及 hs Troponin I 等可能涉及族群、方法或情境差異；v1 使用本筆原院資料，不自動選用男性、女性、年齡或特定檢測方法的替代區間。[院方手冊][S8]本身就有不同適用區間，不能將單一範本當成所有人的基準。

### 尿液、血氣與描述性項目

- 定性規則只對已辨識的對應項目啟用。`Negative`、`Not Found`、`Normal`、`None` 可依該規則顯示 L1；`Positive`、`Trace`、`±`、加號結果顯示異常提醒 L3，不依加號數量推成 L4／L5。
- 尿糖加號不是血糖濃度；SGLT2 類藥物可增加尿糖排泄，須保留用藥情境。[S9]
- 靜脈血 `O2sat`、`PO2` 不是指尖 SpO2，也不能直接套用動脈血氧門檻。[S10] 這些項目仍以本筆原院參考資料顯示。
- 一般 CRP 不套用 hs-CRP 的心血管風險級距；總鈣不當成游離鈣；單一 NT-proBNP 或 hs Troponin I 不被轉成通用五級疾病嚴重度。
- 白血球分類百分比不自動換成絕對計數，也不把總嗜中性球與分葉嗜中性球重複相加。
- `Clear`、`Yellow` 等描述文字保留原文；沒有適用規則時維持未判定。血氣檢驗組別與是否人工閱片是附註，不是測量值。
- LDL 的判讀須注意量測或計算方法；顯著 TG 升高時尤其需要核對，不能只因 LDL 位於原院區間便推定治療目標已達成。[S5]

## 七、歷史年度與來源版本

v1 會以隨版本提供的目前規則，重新顯示工作階段中的歷史紀錄。**它不是依每筆檢查年份，回放當年採用的指引版本**；也沒有歷年規則切換介面。

年度比較仍保留每筆當時回傳的原院參考文字與來源旗標。若顏色來自目前指引或個人設定，就應理解為「用現在這組規則看歷史結果」。來源查核日在 2026 年，不會把 KDIGO 2012、KDIGO 2024、2022 年院方手冊或 AARC 2013 指引改稱為 2026 年版。

## 九、維護者核對事項

可執行邏輯以原始碼包的 `internal/lab/grade.go`、`value.go`、`catalog.go` 為準；來源與定義保存在 `internal/lab/catalog.json`。目錄內的文字契約及尚未啟用資料，不能單獨當作已實作功能的證明。

更新規則時，應同步記錄實際來源版次、適用單位與條件，並檢查精確邊界、包含／不包含端點、不等式、缺值、原院旗標保留，以及個人設定下的獨立警示。現有合成資料測試涵蓋：

- TG、ACR、PCR、eGFR 的精確分類端點及高精度小數。
- 原院參考區間的端點與小數精度，不先四捨五入。
- 不等式／區間不轉成單點；跨分類時的最低可確定警示。
- 異常物理範圍、缺值與流程附註不產生假的安全數字。
- 個人設定不掩蓋獨立警示；eGFR 單位缺失不繞過檢查。
- ACR 共用設定但不合併結果；設定文件不包含觀察結果、日期或就醫機構。
