## 保存什麼

| 位置 | 內容 | 清除方式 |
| --- | --- | --- |
| 設定資料庫 | 官方驗證後的 HMAC 識別碼、外觀、收藏、項目定義、個人門檻、經本人選擇同步的年齡／性別比較條件、設定修訂及修改時間 | 由營運者執行經驗證的刪除程序；備份另有保存期限 |
| 設定庫的執行個體資訊 | 分離用途的 HMAC 金鑰核對值與配對來源狀態；不是原始金鑰、身分或醫療內容 | 隨設定庫備份及刪除；不由公開 API 回傳 |
| 服務密鑰 | `identity.key`，讓已驗證身分在同一服務取得相同設定 | 限服務帳號存取；不放進 SQL、公開目錄或倉庫 |
| 伺服器記憶體 | 當次登入資料、官方 Cookie／權杖及報告 | 登出、逾時清理或服務停止；進行中請求結束後釋放引用 |
| 本機網站儲存 | 使用者選擇記住的證號／卡號、外觀 | 單一使用者「忘記」或設定頁清除全部；亦可由瀏覽器清除 |
| 瀏覽器／系統密碼管理員 | 使用者自行保存的密碼，可能依其設定同步 | 在該密碼管理員管理；網站清除按鈕不會移除它 |
| 當前頁面記憶體 | 未保存的臨時比較條件、選填生日及計算結果 | 離開對應頁面、切換工作階段或關閉分頁 |
| 使用者下載位置 | 主動匯出的報表、個人品項或設定 | 使用者自行管理 |
| 當前資料工作區 | 已取得醫療清單、明細、來源範圍及明確加入資料包的附件，僅在頁面記憶體 | 登出、偵測到登入逾時／工作階段變更時、重新載入或關閉分頁；已下載檔案不會被網站自動刪除 |
| 瀏覽器選配品項 | 使用者明確選擇保存的西藥／中藥／補充品名稱、期間與註記，不傳送應用服務 | 於本站清除或由瀏覽器清除網站資料；不提供伺服器備份 |

應用不將原始證號、健保卡號、密碼、官方 Cookie／權杖、檢驗數值寫入 SQL、報告檔或應用日誌。
記憶體處理仍是資料處理，不是「完全沒有接觸個資」。具有資料或已登入的伺服器工作階段閒置逾時為30分鐘；匿名／挑戰階段為5分鐘，週期清理每分鐘檢查；
本站 Cookie 不設固定的 30 分鐘 Max-Age；閒置期限由伺服器執行，避免活躍使用時被瀏覽器提前切斷。
瀏覽器的工作階段還原功能可能保留 Cookie，關閉分頁或瀏覽器不保證登出；請使用登出功能。
關閉分頁不等於伺服器立即釋放，更不保證底層記憶體位元已不可恢復。

HMAC 是假名化而非匿名化，不是身分證加健保卡號的可逆加密，也不是登入憑證。
設定可重新連到同一人，收藏與個人門檻亦可能反映健康關注，應以個資保護。
卡號換發不改變設定鍵；只有官方驗證成功才允許存取對應設定。匯入檔案不是身分證明。

完整資料包 `healthbank.dataset.v2` 由瀏覽器產生與解析，仍接受舊 v1。醫療清單、明細及附件不因匯出而寫入伺服器；還原時只有資料包的檢驗原始欄位送至原有記憶體匯入流程，以當前規則重新判讀，其他來源與附件留在目前頁面。還原會結束原官方使用階段，使用獨立匯入模式，不能據此存取原登入者的同步設定。程式／契約／判讀版本描述不是檔案真實性或身分認證。

兩份資料包的差異比較只在當前頁面記憶體進行。PDF／列印專用文件由實際資料在瀏覽器產生，不送到額外轉檔服務；指定分享範圍不帶入排除類別的筆數或原始全域醫療警告。下載檔、瀏覽器列印暫存與印表機儲存由使用者及其環境管理，網站無法代為刪除。

伺服器不保存來源 IP 指紋來實施新工作階段速率限制；使用程序內的總量與時間配額。固定操作代碼、隨機請求識別與傳輸階段用於診斷，不包含原始錯誤本文、醫療 URL／查詢參數或憑證。直接本機維運端點只提供粗粒度容量、資料庫可達與金鑰配對來源狀態，反向代理不得公開它。

下載官方原始檔會經本站伺服器串流或有界記憶體處理。明確提出產製時，健保署可能在自己的服務建立暫存工作；這不等於本站持久保存報告。住院 PDF 的官方暫存刪除會依已觀察的流程嘗試，但沒有可核對的官方成功確認時會保留「未確認」資訊；不能承諾官方或基礎設施絕對零留存。來源 HTML/XML 顯示內容以純文字附件下載，不在本站執行。

伺服器閒置期限不會主動推播清除已顯示的瀏覽器內容；頁面在下一次 API／身分確認偵測失效時清除，關閉頁面則釋放其頁面記憶體。多分頁共用 Cookie，但資料讀取另外核對目前工作階段識別；切換身分、匯入及未知操作結果會重新確認身分，無法確認時清除本頁醫療資料。React 畫面例外只記錄固定診斷碼，不輸出原始例外、元件堆疊或醫療欄位。使用者已下載的檔案及自選保存的本機品項仍依各自清除方式管理。

對外營運前須明示實際營運者、聯絡管道、目的、資料類別、期間、地區、對象、方式、權利行使程序，

健康資料的合法處理依據、書面同意與舉證方式，需依實際營運確認；本版沒有新增隱藏的同意或登入歷史資料表。
頁面說明本身不等於已滿足所有同意／告知要求。公開商用前應由具資格的臺灣法律專業人士審核。
個人／家庭活動例外不可自動套用至公開或商用服務。

須稽核 Nginx／其他代理、CDN／WAF、錯誤追蹤、暫存、交換空間、core dump、主機映像與備份。
隨附 Nginx 片段停用代理快取、請求／回應緩衝及存檔，並將上限內的請求緩衝留於記憶體；
不會改動實際主機或第三方服務。必要診斷保留錯誤碼與階段，不能以關閉所有錯誤輸出冒充零留存。
舊資料、舊瀏覽器記憶與歷史備份不會只因更新程式就消失；先盤點，再依明確範圍清除及記錄結果。
