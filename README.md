# 健康映覽 · Healthbank

![Healthbank：自架檢驗報告比較與長期趨勢](docs/assets/healthbank-banner.svg)

**從健康存摺取得授權資料，以自己的方式整理醫療時間軸、比較歷年檢驗、查看處方與原始報告。**

[下載與發行](https://github.com/bestkakkoii/healthbank/releases) · [部署](docs/deployment.zh-TW.md) · [資料處理](docs/privacy.zh-TW.md) · [驗證](docs/verification.zh-TW.md) · [深度稽核](docs/deep-audit.zh-TW.md) · [實機驗收](docs/acceptance.zh-TW.md)

獨立 MIT 開源專案，非健保署官方服務。Go 執行檔內嵌 React 前端；SQLite 預設、MySQL 選用。
不要求特定主機面板、額外會員帳號或日常打卡。前端不載入外部腳本、字型或廣告分析服務。

## 功能

| 功能 | 邊界 |
| --- | --- |
| 全歷史查詢 | 明確送出日期範圍、保留來源及同日多筆；官方實際留存範圍仍適用，不把收到陣列當作終身完整證明 |
| 年度比較 | 日期為列、項目為欄；搜尋、收藏、年度篩選及可見橫向控制 |
| 趨勢 | 修正同日多筆造成的前段斷線；真實日期／檢查日期等距可切換，保留每筆精確數值與原始明細，區間或不等式不偽造單點 |
| 年齡／性別情境 | 本人與比較條件並列、即時生效；提供九項來源具名範本（實際年齡／性別分層依來源而定），符合條件後可估算CKD-EPI 2021；不覆寫原院數據 |
| 個人基準 | 未匯入也顯示內建項目，支援個別／全部還原；官方驗證後跨裝置同步 |
| 登入記憶 | 私人裝置自選記住多位使用者的證號／卡號；密碼由瀏覽器管理，驗證碼由本人輸入 |
| 匯入與輸出 | HTML／ZIP及本站版本化 JSON／XML 可攜報表匯入；CSV、JSON（明確 UTF-8，選配 BOM）、XML、SVG及列印匯出。不是健保署任意同名格式的通用匯入器 |
| 醫療資料工作區 | 將健保署作為授權身分與資料來源；Healthbank 提供自己的來源選擇、最大範圍拉取、逐筆明細、取消／續取、跨來源搜尋與時間軸。清單、明細及未取得項目分別呈現，畫面篩選不影響已取得內容 |
| 擴充來源 | 用藥／慢箋／電子處方與續領、自費藥品與醫材、西／中／牙醫就醫、手術／住院、過敏、接種、各類篩檢、照護追蹤、生理量測及既有自行紀錄；只讀取有公開來源契約的欄位，實際帳號範圍仍須驗收 |
| 原始報告與附件 | 影像／病理文字、官方 JPEG 組、住院 PDF 與病摘顯示內容、官方已產製原始檔及 DICOM 下載。需要產製時由使用者明確提出，保留官方原始檔格式 |
| 完整資料包 | UTF-8 healthbank.dataset.v1，含全部已取得清單、明細、範圍、未完成狀態及已加入的附件；可重新匯入獨立工作階段。附件校驗 SHA-256，不匯出登入憑證或可重用操作識別 |
| 藥品時間圖／個人品項 | 同官方藥品代碼彙整歷次處方給藥日數；同日多值保留、未知日數不連線，全部來源紀錄可翻頁查看。不推定實際服藥、劑量或斷藥。另有選配裝置端西藥、中藥、補充品紀錄，不上傳伺服器 |
| 輔助分析 | 多指標同日期軸、前後差值；高 TG 下先保留院所原始 LDL，Friedewald 不適用時明示；僅於研究適用範圍內選配 Sampson 估算及同次 non-HDL |

淺色／深色／跟隨系統，支援應用字級放大。手機不固定日期欄，桌面保留固定日期。
實體iOS、密碼管理員、真實官方資料完整性與實際部署各自驗收，不用模擬測試替代。

「全部範圍」表示對支援日期搜尋的來源送出民國 1 年至臺灣當日，其餘來源讀取官方提供的全部回應；不承諾官方保有終身紀錄。近期摘要、最近兩次／三次檢查與沒有獨立總數的來源均保留限制說明。新增來源不會因檢驗日期表單或畫面年度篩選而默默縮小範圍。

原始文件串流下載上限 500 MiB；需要先在記憶體驗證的 PDF／JPEG 組另有 32 MiB 限制。完整資料包上限 128 MiB，其中檢驗內容與明確加入的附件各上限 32 MiB，大型原始檔另存。資料包會標示尚未取得的明細與尚未加入的附件，不把部分資料稱為完整備份。操作及 API 見[資料工作區與可攜格式](docs/data-workspace.zh-TW.md)。

資料匯入會拒絕重複 JSON 欄位與損壞的 Unicode；原始日期文字與正規化日期分別保留。多分頁切換、工作階段失效及匯入／登出回應中斷時，會核對目前身分，避免混用不同資料包或留下舊醫療內容。單一來源匯出與完整資料包都移除當次官方操作識別。

## 部署

下載符合CPU架構的Linux發行包，解壓並執行 `healthbank`；對外由HTTPS反向代理轉送。
預設監聽 `127.0.0.1:8787`，在執行檔旁建立 `data/`。不用安裝Go、Node.js、Python、Chromium或SQLite服務。
部署方式、系統服務與代理配置見[部署文件](docs/deployment.zh-TW.md)。

| 範圍 | 支援與查核 |
| --- | --- |
| 主要目標 | Debian 13（trixie）x86_64；Linux amd64靜態執行檔 |
| 其他架構 | Linux arm64交叉編譯；原生機器驗收另列 |
| 瀏覽器 | 持續更新的Chrome、Edge、Firefox、Safari；需要JavaScript與工作階段Cookie，伺服器另設30分鐘閒置期限 |
| 行動裝置 | 以iOS Safari為重點；原生縮放、密碼自動填入、鍵盤與橫直向須實機驗收 |
| 網路與作業系統 | 有效CA信任、正確時間、DNS及對外HTTPS；部署平台不限定面板 |
| 開發 | 工具來源、版本、提交及相容性限制集中在鎖定檔與[依賴文件](DEPENDENCIES.md) |

尚未建立通用最低瀏覽器版號或硬體下限，不杜撰可用範圍。預覽版在Releases明確標示；Latest不一定指向預覽版。

## 資料保存

- **SQL只保存假名化識別碼與設定**，不保存原始證號、卡號、密碼、官方權杖，亦不保存檢驗、用藥、就醫、手術或住院原文。假名化不等於匿名，設定仍需保護。
- **官方工作階段與報告只在記憶體**。API回應不快取；代理、CDN、交換空間、轉存及備份須由實際營運者另行稽核。
- **裝置記憶由使用者選擇**，可忘記單人或全部。密碼不寫入網站儲存；密碼管理員可能要求生物辨識並依其設定同步。
- **比較情境由本人明確選擇儲存**；年齡／性別比較條件可於官方驗證後作為假名化設定同步。生日只留在瀏覽器當前頁面，不傳送或保存。檢驗與官方醫療資料會經伺服器及瀏覽器記憶體處理，不寫入設定資料庫；使用者主動匯出的檔案由本人管理。

更新前停止服務，保留並備份 `data/`，尤其 `identity.key` 與設定資料庫須一起保留。
登入逾時、登出或服務重啟後需重新取得報告。詳見[隱私與資料處理](docs/privacy.zh-TW.md)。
